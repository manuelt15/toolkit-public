# Arquitecturas

Una por tipo de proyecto. Cada una dice cómo se monta y qué módulos recomienda; la skill
`nuevo-proyecto` la usa para preseleccionarlos. Para añadir una: skill `anadir-al-toolkit`.

| Arquitectura | Para |
|---|---|
| [saas](saas.md) | App con usuarios, cuentas y pagos |
| [landing](landing.md) | Web de marketing o estática |
| [agente-ia](agente-ia.md) | App centrada en agentes o IA |
| [api](api.md) | Backend sin interfaz |
| [herramienta](herramienta.md) | Uso personal o interno, pocos usuarios |

## Para aprender y decidir
- [System Design Primer](https://github.com/donnemartin/system-design-primer): recursos para
  diseñar sistemas a gran escala (caché, colas, bases de datos, escalado). Consultar cuando
  una arquitectura se queda pequeña o hay que justificar una decisión en un ADR.
